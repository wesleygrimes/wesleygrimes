# Wes Grimes

I'm a developer in North Carolina building open-source tools for Omarchy and Wayland.
Shipping software since the '90s.

## What I build

- [Omastorm](https://omastorm.com): Live weather radar for the Omarchy desktop, built with Rust and Quickshell. [Source](https://github.com/wesleygrimes/omastorm).
- [Wayshare](https://github.com/wesleygrimes/wayshare): Share your Hyprland desktop with a Mac using its built-in Screen Sharing app, including High Performance mode. Nothing to install on macOS. Copy and paste text, rich text, and images.

Install Wayshare:

```sh
curl -fsSL https://raw.githubusercontent.com/wesleygrimes/wayshare/main/install.sh | sh
```

## Smaller tools

- [omarchy-weather](https://github.com/wesleygrimes/omarchy-weather): Live weather on the Omarchy bar. Click the pill for the forecast.
- [omarchy-notched](https://github.com/wesleygrimes/omarchy-notched): An Omarchy bar that makes room for the MacBook camera notch.
- [omavolt](https://github.com/wesleygrimes/omavolt): Omarchy battery popup with PowerTOP energy diagnostics.
- [omarchy-eternia-theme](https://github.com/wesleygrimes/omarchy-eternia-theme): A vivid retro-futuristic Eternia theme for Omarchy.
- [wedge](https://github.com/wesleygrimes/wedge): An open-source regional weather model for cold-air damming in the Carolinas and Mid-Atlantic.
